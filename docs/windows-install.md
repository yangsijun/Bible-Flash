# Bible Flash Windows 설치 가이드

예배 중 성경 구절을 프로젝터(보조 모니터)에 띄우는 Bible Flash를 Windows PC에 설치하고 설정하는 방법입니다.

전체 흐름은 세 단계입니다.

1. **설치 파일 만들기**: 개발용 Windows PC에서 `Setup.exe`를 만듭니다.
2. **교회 PC에 설치**: `Setup.exe`를 실행하고, 첫 실행 때 성경 DB 파일을 고릅니다.
3. **모니터 설정**: 출력 모니터를 고르고 화면을 맞춥니다.

**성경 DB는 설치 파일에 들어 있지 않은 별도 파일입니다.** 프로그램을 다시 설치하지 않고도 DB 파일만 바꿀 수 있습니다.

이미 만들어진 `Setup.exe`를 받았다면 [2단계](#2단계-교회-pc에-설치)부터 보면 됩니다.

> 설치 파일은 Windows에서 만드는 것을 권장합니다. macOS에서 Windows 설치 파일을 만들려면 Wine과 Mono가 따로 필요합니다.

---

## 준비물

| 항목 | 내용 |
| --- | --- |
| Windows PC | Windows 10 또는 11, 64비트 |
| Node.js | LTS 버전 (설치 파일을 만드는 PC에만 필요) |
| 소스 코드 | 이 저장소 (`git clone` 또는 폴더 복사) |
| 성경 원본 DB | `Bible_NKRV.sqlite` (개역개정). 개역한글은 `Bible_KRV.sqlite` |
| 글꼴 (선택) | 나눔바른고딕. 없으면 맑은 고딕으로 표시됩니다 |

- 성경 DB 파일은 **git과 설치 파일 어디에도 포함되지 않습니다.** USB나 클라우드 드라이브로 교회 PC에 따로 옮겨야 합니다.
- Visual Studio 빌드 도구는 **필요 없습니다.** 네이티브 모듈을 쓰지 않습니다.

---

## 1단계: 설치 파일 만들기

개발용 Windows PC의 PowerShell에서 진행합니다.

### 1-1. Node.js 확인

```powershell
node -v
```

버전이 나오지 않으면 [nodejs.org](https://nodejs.org)에서 LTS를 설치하세요.

### 1-2. 의존성 설치

```powershell
cd Bible-Flash\bible-flash
npm install
```

Electron 실행 파일도 이때 내려받으므로 몇 분 걸릴 수 있습니다.

### 1-3. 실행해 보기 (선택)

```powershell
npm start
```

처음 실행하면 "성경 DB 파일이 없습니다" 안내가 뜹니다. **파일 선택**으로 `Bible_NKRV.sqlite`를 고른 뒤, `요 3:16`을 입력해 Enter를 눌렀을 때 구절이 표시되면 정상입니다.

### 1-4. 설치 파일 만들기

```powershell
npm run make
```

결과물은 아래 폴더에 생깁니다.

```
bible-flash\out\make\squirrel.windows\x64\
```

이 폴더 안의 `Setup.exe`로 끝나는 파일이 설치 파일입니다. 성경 DB 없이 만들어지므로, 교회 PC에는 DB 파일을 따로 가져가야 합니다.

## 2단계: 교회 PC에 설치

### 2-1. Setup.exe 실행

1. `Setup.exe`를 교회 PC로 복사해 더블클릭합니다.
2. 설치는 자동으로 진행되고, 끝나면 Bible Flash가 바로 실행됩니다.
3. 바탕화면과 시작 메뉴에 바로가기가 생깁니다.

관리자 권한은 필요 없습니다. 현재 Windows 사용자 계정에만 설치됩니다.

### 2-2. "Windows의 PC 보호" 경고가 뜰 때

설치 파일에 코드 서명이 없어서 SmartScreen 경고가 나올 수 있습니다.

1. **추가 정보**를 누릅니다.
2. **실행**을 누릅니다.

### 2-3. 설치 위치

| 내용 | 위치 |
| --- | --- |
| 프로그램 | `%LOCALAPPDATA%\bible-flash` |
| 성경 DB와 설정 | `%APPDATA%\bible-flash` |

탐색기 주소창에 위 경로를 그대로 입력하면 열립니다.

### 2-4. 성경 DB 파일 고르기 (첫 실행 때 한 번)

1. 처음 실행하면 **"성경 DB 파일이 없습니다"** 안내가 뜹니다.
2. **파일 선택**을 누르고 `Bible_NKRV.sqlite`를 고릅니다.
3. 파일을 검사한 뒤 `%APPDATA%\bible-flash\bible.sqlite`로 복사하고 바로 사용합니다.

**나중에**를 눌렀다면 메뉴의 **Setting > Load Database**로 언제든 고를 수 있습니다.

## 3단계: 모니터 설정

### 3-1. Windows 디스플레이를 "확장"으로

1. 프로젝터나 보조 모니터를 연결합니다.
2. `Windows 키 + P`를 누르고 **확장**을 선택합니다.

**복제** 모드에서는 조작 화면이 프로젝터에도 그대로 보입니다.

### 3-2. 출력 모니터 고르기

Bible Flash는 처음에 **주 모니터가 아닌 첫 번째 모니터**를 출력 화면으로 씁니다. 다른 모니터를 쓰려면 아래와 같이 고릅니다.

1. 조작 창 메뉴에서 **Display**를 엽니다.
2. `디스플레이 N  모니터이름  해상도` 목록에서 프로젝터를 고릅니다. 주 모니터에는 `(주 모니터)`가 붙어 있습니다.

- 고른 모니터는 저장되어 다음 실행 때도 그대로 쓰입니다.
- 모니터를 뺐다 다시 꽂으면 저장된 모니터로 자동으로 돌아갑니다.
- 출력 모니터가 조작 창과 같은 화면이면(모니터가 1대일 때 등), 출력 창이 960×540 크기의 일반 창으로 열립니다. 조작 창을 가리지 않게 하기 위해서입니다.

### 3-3. 화면 꾸미기

**View** 메뉴에서 바꿉니다. 설정은 자동으로 저장됩니다.

| 메뉴 | 내용 |
| --- | --- |
| Change Background Image | 배경 이미지 (jpg, png) |
| Font Size | 32 / 40 / 48 / 60pt |
| Opacity Dark | 배경을 어둡게 하는 정도 0.3 ~ 0.8 |

## 사용법 요약

### 구절 입력

입력창에 쓰고 **Enter** 또는 **표시**를 누릅니다.

| 입력 예 | 결과 |
| --- | --- |
| `요 3:16`, `요3:16`, `요 3 16`, `요3.16` | 요한복음 3장 16절 |
| `요한복음 3장 16절` | 요한복음 3장 16절 |
| `마태 5` | 마태복음 5장 1절 (절을 빼면 1절) |
| `고전 13:4-7` | 고린도전서 13장 4절부터 시작, **다음**으로 이어서 넘김 |

- 책 이름을 입력하면 **자동완성 목록**이 나옵니다. `ㅁㅌ`처럼 초성만 입력해도 됩니다.
- 책 이름이나 구절이 틀리면 **출력 화면은 그대로 두고**, 조작 창에 빨간 안내만 나옵니다.
- 아래쪽 드롭다운에서 성경, 장, 절을 고르면 바로 표시됩니다.

### 단축키

| 키 | 동작 |
| --- | --- |
| `Enter` | 입력한 구절 표시 (자동완성 목록이 열려 있으면 선택한 책 이름 입력) |
| `↑` `↓` / `Tab` | 자동완성 목록에서 이동 / 선택 |
| `PageDown` | 다음 구절 (장과 책을 넘어감) |
| `PageUp` | 이전 구절 |
| `→` `←` | 다음 / 이전 구절 (**입력창에 커서가 없을 때만**) |
| `Esc` | 출력 화면 숨기기 |

프레젠터 리모컨(클리커)은 보통 `PageDown`/`PageUp`을 보내므로 그대로 쓸 수 있습니다.

## 예배 전 점검 목록

- [ ] `Windows 키 + P`가 **확장**으로 되어 있다
- [ ] **Display** 메뉴에서 프로젝터가 선택되어 있다
- [ ] `요 3:16`을 입력해 프로젝터에 표시되는 것을 확인했다
- [ ] 리모컨으로 다음/이전이 넘어가는 것을 확인했다
- [ ] 가장 긴 구절 `렘 32:3`(287자)도 화면 밖으로 잘리지 않는다 (잘리면 **View > Font Size**를 줄임)
- [ ] `Esc`로 출력 화면이 숨겨진다

## 문제 해결

| 증상 | 원인과 해결 |
| --- | --- |
| "성경 DB 파일이 없습니다" | 첫 실행이거나 DB 파일이 지워진 상태입니다. **파일 선택** 또는 **Setting > Load Database**로 `Bible_NKRV.sqlite`를 고릅니다 |
| "DB 파일을 저장하지 못했습니다" | 백신 프로그램 등이 파일을 잠시 잡고 있을 수 있습니다. 잠시 후 **Setting > Load Database**를 다시 시도합니다 |
| "성경 DB 파일을 읽을 수 없습니다" | `%APPDATA%\bible-flash\bible.sqlite`가 망가졌거나 다른 파일입니다. **Setting > Load Database**로 원본 파일을 다시 고릅니다 |
| 조작 창에 "성경 DB가 열려 있지 않습니다" | DB를 아직 고르지 않았습니다. **Setting > Load Database**로 고릅니다 |
| 출력 창이 조작 창을 덮음 | `Windows 키 + P` → **확장**을 고른 뒤 **Display** 메뉴에서 프로젝터를 다시 고릅니다 |
| 엉뚱한 모니터에 출력됨 | **Display** 메뉴에서 맞는 모니터를 고릅니다. 같은 모델 모니터가 2대면 이름 대신 해상도와 순서로 구분합니다 |
| `→` 키로 안 넘어감 | 입력창에 커서가 있으면 화살표 키는 글자 이동에 쓰입니다. `PageDown`을 쓰거나 창의 빈 곳을 클릭합니다 |
| 자동완성에서 Enter를 두 번 눌러야 함 | 한글 조합 중에 Enter를 누르면 Windows에서 생길 수 있습니다. 한 번 더 누르면 됩니다 |
| 글꼴이 의도와 다름 | 나눔바른고딕을 설치하면 그 글꼴로 바뀝니다. 없으면 맑은 고딕으로 표시됩니다 |
| 출력 창이 사라짐 | `Esc`로 숨긴 상태입니다. 구절을 다시 표시하면 나타납니다 |
| 모니터 설정을 처음으로 되돌리고 싶음 | 프로그램을 끄고 `%APPDATA%\bible-flash\settings.json`을 지웁니다 |

## 업데이트와 성경 DB 교체

### 프로그램 업데이트

1. `bible-flash\package.json`의 `"version"`을 올립니다 (예: `1.0.0` → `1.0.1`).
2. `npm run make`로 새 `Setup.exe`를 만듭니다.
3. 교회 PC에서 새 `Setup.exe`를 실행합니다. 설정과 불러온 DB는 그대로 남습니다.

버전을 올리지 않으면 기존 설치를 제대로 덮어쓰지 못할 수 있습니다.

### 성경 DB 바꾸기 (재설치 없이)

성경 DB는 원본 파일이 **변환 없이 그대로** `%APPDATA%\bible-flash\bible.sqlite`에 저장된 것입니다. 바꾸는 방법은 두 가지입니다.

**메뉴로 바꾸기 (권장)**

1. **Setting > Load Database**를 엽니다.
2. `Bible_KRV.sqlite`처럼 같은 형식의 원본 DB를 고릅니다.
3. 바로 새 DB로 바뀌고 조작 창이 새로고침됩니다. 출력 화면은 숨겨지니, 구절을 다시 표시하세요.

고른 파일이 성경 DB가 아니면 오류를 보여 주고, **기존 DB는 그대로 둡니다.**

**파일을 직접 바꾸기**

1. Bible Flash를 끕니다.
2. 탐색기에서 **보기 > 파일 확장명**을 켭니다. 꺼져 있으면 이름이 `bible.sqlite.sqlite`가 되어 인식되지 않습니다.
3. 새 원본 파일을 `%APPDATA%\bible-flash\`에 복사하고 이름을 `bible.sqlite`로 바꿉니다. 기존 파일은 덮어씁니다.
4. Bible Flash를 다시 켭니다.

DB 파일은 66권과 3만 개 이상의 구절이 있는지 검사한 뒤에 사용됩니다. 원본 형식은 `bible_book`, `bible_verse`, `bible_book_abbreviation` 테이블이 있는 SQLite 파일입니다.

### 저장되는 파일

| 파일 | 내용 |
| --- | --- |
| `%APPDATA%\bible-flash\settings.json` | 고른 출력 모니터 |
| `%APPDATA%\bible-flash\bible.sqlite` | 성경 DB (원본 파일 그대로) |
| `%APPDATA%\bible-flash\Local Storage\` | 배경 이미지 경로, 글자 크기, 어둡기 |

배경 이미지는 경로만 저장됩니다. 이미지 파일을 옮기거나 지우면 배경이 사라지니, 원본은 고정된 폴더에 두세요.
